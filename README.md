# Cordel Scroll Challenge – HTML & CSS Project

This project was developed as part of the **HTML5 and CSS3 course from Curso em Vídeo**.  
It demonstrates a scrolling effect where background images change as the user scrolls, combined with overlay text.  

It’s a visual exercise designed to practice layout, positioning, and responsive design using only HTML and CSS.

---

## 🎯 Project Goals

- Practice semantic HTML5 structure  
- Experiment with CSS backgrounds and positioning  
- Create scrolling effects with static images and text  
- Understand layout changes as the page scrolls  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  

---

## 🌐 Deployment

This project is deployed using **GitHub Pages** [https://gabriellecalabria.github.io/html-css-cordel/]

## 📚 What I Learned

- How to structure content for scrolling effects  
- Using CSS for background positioning and overlays  
- Working with multiple sections and images in a single page  
- Making the layout visually appealing without JavaScript
